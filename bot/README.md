# 🤖 ربات تلگرام پروتکل تشخیص دوگانه (بخش اصلی ربات)

ربات تلگرامِ [پروتکل درمان تشخیص دوگانه](../README.md) — **مستقل و سبک**، بدون هیچ وابستگی سنگین
(بدون torch/transformers؛ فقط `python-telegram-bot`).

## معماری: بخش اصلی + بخش هوش مصنوعی

```
┌───────────────────────────────┐        ┌──────────────────────────────────┐
│  بخش اصلی (این مخزن)          │        │  بخش هوش مصنوعی                   │
│  dual-diagnosis-protocol      │        │  SBZ-EDU/dual-diagnosis-rag      │
│                               │  ───►  │  + ورکر Cloudflare               │
│  • متن کامل پروتکل درمان      │  HTTP  │  • بازیابی معنایی ۲۰۰+ مقاله      │
│  • پایش خطر ۷ شاخصه           │        │  • مدل زبانی (پاسخ فارسی)         │
│  • آموزش روزانه               │        │  • راهنماها: NICE·APA·WFSBP·WHO  │
│  • جست‌وجوی آفلاین در پروتکل   │        │    (fallback محلی همین ربات)      │
└───────────────────────────────┘        └──────────────────────────────────┘
```

پرسش آزاد کاربر به دستیار هوش مصنوعی (ورکر کلودفلر) فرستاده می‌شود؛ اگر سرویس در دسترس
نباشد، ربات به‌صورت آفلاین در متن پروتکل جست‌وجو می‌کند و پاسخ محلی می‌دهد.

## امکانات

- 🎛 **منوی دکمه‌ای پایین چت**: پایش خطر · نکته امروز · بخش‌های پروتکل · راهنما
- 📈 `/risk` — ارزیابی خطر ۷ شاخصه (۰ تا ۴) با امتیاز شفاف، سطح و اقدام پیشنهادی
- 🎓 `/tip` — نکته‌ی آموزشی روز (۱۴ موضوع چرخشی، همه با ذکر منبع)
- 📖 `/sections` — مرور بخش‌های پروتکل با دکمه‌های درون‌پیام
- 💬 پیام آزاد — پاسخ فارسی از دستیار هوش مصنوعی (یا جست‌وجوی آفلاین پروتکل)
- 🔒 بدون ذخیره‌سازی پیام‌ها؛ ارزیابی خطر بدون نام بیمار

## 👤 نقش کاربر و 📈 پیگیری روند

- **انتخاب نقش** — دکمه‌ی «👤 نقش من» یا `/role`: بیمار / همراه خانواده / متخصص.
  نقش انتخابی به بخش هوش مصنوعی (ورکر) فرستاده می‌شود و لحن و سطح پاسخ‌ها را تنظیم می‌کند
  (خانواده: اقدامات حمایتی و علائم هشدار؛ متخصص: زبان فنی و محدودیت شواهد).
- **سابقه‌ی پایش خطر** — بعد از هر `/risk` فقط *امتیاز، سطح و تاریخ* (بدون نام و متن پیام)
  ذخیره می‌شود؛ `/history` روند را با تاریخ شمسی و جهت تغییر (⬆️⬇️) نشان می‌دهد
  و در صورت بدتر شدن روند، به تماس با پزشک توصیه می‌کند.
- داده‌ها با `PicklePersistence` در `data/bot_data.pkl` (گیت‌نادیده) بین اجراها می‌مانند — بدون پایگاه‌داده.

## 📢 انتشار خودکار در کانال (اختیاری)

ربات می‌تواند هر روز ساعت ۹ صبح (به وقت تهران) «نکته‌ی آموزشی روز» را در کانال تلگرام منتشر کند.

۱) ربات را در کانال **به‌عنوان مدیر با دسترسی «ارسال پیام»** اضافه کنید.
۲) `TELEGRAM_CHANNEL_ID` را در `.env` تنظیم کنید (کانال عمومی: `@username`؛ خصوصی: شناسه‌ی عددی `-100...`).
۳) ربات را اجرا کنید — زمان‌بندی خودکار فعال می‌شود.

دستورهای مرتبط (در فهرست عمودی نمایش داده نمی‌شوند):
- `/channel_status` — بررسی اتصال و لینک کانال
- `/post_tip` — ارسال فوری نکته‌ی امروز (خنک‌سازی ۱۰ دقیقه‌ای ضد اسپم)

> نکته: نام کاربری ربات در پیام‌های Markdown باید با `\_` از زیرخط‌ها ایمن شود (محدودیت تلگرام).

## اجرا

```bash
pip install -r bot/requirements.txt

# توکن را در .env کنار مخزن بگذارید (این فایل گیت‌نادیده است):
#   TELEGRAM_BOT_TOKEN=123456:ABC...
#   AI_API_URL=https://dual-diagnosis-clinical-hub.elasa2next.workers.dev/api/chat

python bot/telegram_bot.py
```

> ⚠️ هر توکن فقط یک نمونه‌ی فعال می‌پذیرد؛ اگر رباتِ مخزن `dual-diagnosis-rag` هم روشن
> باشد، یکی از دو نمونه خطای تداخل (409) می‌گیرد.
