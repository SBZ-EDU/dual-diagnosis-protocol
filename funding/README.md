# 💰 یابنده‌ی شتاب‌دهنده و اعتبار — ماژول تأمین مالی پروژه

ابزار «گرفتن پول برای پروژه»: بانک برنامه‌های شتاب‌دهی/اعتبار ابری + تولید خودکار
پیش‌نویس درخواست برای هر برنامه + داشبورد وضعیت.

## ساختار

| فایل | نقش |
|---|---|
| `programs.json` | بانک داده‌ی ۱۳ برنامه (مهلت، مزایا، سهام، مانع‌ها، لینک، تاریخ تأیید) |
| `profile.md` | پروفایل اصلی استارت‌آپ — **منبع حقیقت همه‌ی درخواست‌ها** (مشکل، راه‌حل، traction، تیم، درخواست) |
| `generate.py` | تولید پیش‌نویس درخواست هر برنامه (`proposals/*.md`) + داشبورد (`dashboard.html`) |
| `check_status.py` | گرفتن صفحات رسمی برنامه‌ها و گزارش باز/بسته/قابل‌دسترس + تاریخ بررسی |
| `proposals/` | پیش‌نویس‌های تولیدشده (گیت‌نادیده — شامل اطلاعات تماس است) |
| `dashboard.html` | داشبورد فارسی وضعیت، مهلت‌ها و برنامه‌ی اقدام |

## گردش کار

```bash
# ۱) وضعیت صفحات رسمی را بررسی کن
python funding/check_status.py

# ۲) (در صورت تغییر) programs.json را ویرایش کن — یا از دستیار هوشمند بخواه

# ۳) پیش‌نویس‌ها و داشبورد را بازتولید کن
python funding/generate.py
```

تنظیمات تماس در `.env` (گیت‌نادیده):

```
FUNDING_CONTACT_EMAIL=...
FUNDING_WHATSAPP=...
```
